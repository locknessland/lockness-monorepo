# Lockness Framework Documentation for LLMs

Lockness is a fullstack MVC Web framework for Deno, inspired by Laravel and AdonisJS, powered by HonoJS.

## Quick Start

```bash
# Initialize new project
deno run -A jsr:@lockness/init my-app
cd my-app

# Start development server
deno task dev

# Create a controller
deno task cli make:controller User
deno task cli make:controller User --view  # With JSX view

# Create a model with repository, seeder, controller
deno task cli make:model Post -a
```

## Core Concepts

### Controllers & Routing

Class-based controllers with decorators:

```typescript
import { Controller, Get, Post, Put, Delete, Context } from '@lockness/core'

@Controller('/api/users')
export class UserController {
    @Get('/', { name: 'users.index' })
    async index(c: Context) {
        return c.json({ users: [] })
    }

    @Get('/:id', { name: 'users.show' })
    async show(c: Context) {
        const id = c.req.param('id')
        return c.json({ id })
    }

    @Post('/')
    async store(c: Context) {
        const body = await c.req.json()
        return c.json(body, 201)
    }

    @Put('/:id')
    async update(c: Context) {
        const id = c.req.param('id')
        const body = await c.req.json()
        return c.json({ id, ...body })
    }

    @Delete('/:id')
    async destroy(c: Context) {
        const id = c.req.param('id')
        return c.json({ deleted: true })
    }
}
```

Available decorators: @Get, @Post, @Put, @Delete, @Patch, @Options, @Head

Generate URLs from named routes:
```typescript
import { route } from '@lockness/core'

const url = route('users.show', { id: 123 }) // "/api/users/123"
return c.redirect(route('auth.login'))
```

### Dependency Injection

Built-in IoC container with TC39 decorators:

```typescript
import { Service, Inject } from '@lockness/core'

@Service()
export class UserService {
    async findAll() {
        return []
    }
}

@Controller('/users')
export class UserController {
    @Inject(UserService)
    accessor userService!: UserService

    @Get('/')
    async index(c: Context) {
        const users = await this.userService.findAll()
        return c.json({ users })
    }
}
```

### Database (Drizzle ORM)

Type-safe PostgreSQL with Drizzle:

```typescript
// src/model/user.ts
import { pgTable, serial, text, timestamp } from 'drizzle-orm/pg-core'
import { createInsertSchema, createSelectSchema } from 'drizzle-zod'
import { z } from 'zod'

export const users = pgTable('users', {
    id: serial('id').primaryKey(),
    name: text('name').notNull(),
    email: text('email').notNull().unique(),
    password: text('password').notNull(),
    createdAt: timestamp('created_at').defaultNow(),
    updatedAt: timestamp('updated_at').defaultNow(),
})

// Auto-generate Zod schemas
export const insertUserSchema = createInsertSchema(users, {
    email: z.string().email(),
    password: z.string().min(8),
})
export const selectUserSchema = createSelectSchema(users)

export type User = typeof users.$inferSelect
export type NewUser = typeof users.$inferInsert
```

Repository pattern:

```typescript
import { Service, Inject } from '@lockness/core'
import { Database } from '@lockness/drizzle'
import { users, type User } from '@model/user.ts'

@Service()
export class UserRepository {
    @Inject(Database)
    accessor db!: Database

    async findAll(): Promise<User[]> {
        return await this.db.db.select().from(users)
    }

    async findById(id: number): Promise<User | null> {
        const result = await this.db.db
            .select()
            .from(users)
            .where(eq(users.id, id))
        return result[0] || null
    }

    async create(data: NewUser): Promise<User> {
        const result = await this.db.db
            .insert(users)
            .values(data)
            .returning()
        return result[0]
    }
}
```

### Validation

Request validation with Zod + drizzle-zod:

```typescript
import { Controller, Post, Validate, Context } from '@lockness/core'
import { insertUserSchema } from '@model/user.ts'

@Controller('/api/users')
export class UserController {
    @Post('/')
    @Validate('json', insertUserSchema)
    async store(c: Context) {
        const validated = c.req.valid('json')
        return c.json(validated, 201)
    }
}
```

Validation targets: 'json', 'query', 'param', 'header', 'cookie', 'form'

Error response format:
```json
{
    "success": false,
    "errors": {
        "email": ["Invalid email format"],
        "password": ["Password must be at least 8 characters"]
    }
}
```

### Authentication

Session-based authentication system:

```typescript
// Generate auth scaffolding
deno task cli make:auth

// Configure in kernel.ts
import { configureAuth, container } from '@lockness/core'
import { UserProvider } from '@provider/user_provider.ts'

configureAuth({
    userProvider: container.get(UserProvider),
    redirectTo: '/auth/login',
})

// Use in controllers
import { Auth, Guest, auth, session } from '@lockness/core'

@Controller('/dashboard')
@Auth() // Protect entire controller
export class DashboardController {
    @Get('/')
    async index(c: Context) {
        const user = auth(c).user()
        return c.json({ user })
    }
}

@Controller('/auth')
export class AuthController {
    @Guest('/dashboard') // Redirect if authenticated
    @Get('/login')
    login(c: Context) {
        return c.html(<LoginPage />)
    }

    @Post('/login')
    async handleLogin(c: Context) {
        const { email, password } = await c.req.json()
        
        if (await auth(c).attempt(email, password)) {
            session(c).regenerate()
            return c.redirect('/dashboard')
        }
        
        return c.json({ error: 'Invalid credentials' }, 401)
    }

    @Post('/logout')
    async logout(c: Context) {
        await auth(c).logout()
        return c.redirect('/auth/login')
    }
}
```

Auth API:
- `auth(c).check()` - Is authenticated?
- `auth(c).user()` - Get current user
- `auth(c).id()` - Get user ID
- `auth(c).attempt(email, pass)` - Try login
- `auth(c).login(user)` - Log in user
- `auth(c).logout()` - Log out

Password hashing:
```typescript
import { hashPassword, verifyPassword } from '@lockness/core'

const hash = await hashPassword('secret123')
const valid = await verifyPassword('secret123', hash)
```

### Sessions

Multi-driver session management:

```typescript
// Configure in kernel.ts
import { configureSession, createSessionMiddleware } from '@lockness/core'

configureSession({
    driver: 'cookie', // or 'deno-kv' or 'memory'
    cookieName: 'lockness_session',
    secret: Deno.env.get('APP_KEY')!,
    maxAge: 7 * 24 * 60 * 60,
    secure: Deno.env.get('APP_ENV') === 'production',
})

// Configure session middleware using fluent API
app.useMiddleware(createSessionMiddleware())

await app.init({
    controllers,
})

// Use in controllers
import { session } from '@lockness/core'

@Controller('/cart')
export class CartController {
    @Post('/add')
    async add(c: Context) {
        const cart = session(c).get('cart', [])
        cart.push({ id: 1, name: 'Product' })
        session(c).set('cart', cart)
        
        // Flash message for next request
        session(c).flash('success', 'Added to cart!')
        
        return c.redirect('/cart')
    }

    @Get('/')
    async index(c: Context) {
        const cart = session(c).get('cart', [])
        const message = session(c).getFlash('success')
        return c.json({ cart, message })
    }
}
```

Session API:
- `get(key, default?)` - Get value
- `set(key, value)` - Set value
- `has(key)` - Check if exists
- `forget(key)` - Remove key
- `all()` - Get all data
- `flush()` - Clear all
- `regenerate()` - Regenerate ID
- `destroy()` - Destroy session
- `flash(key, value)` - Flash for next request
- `getFlash(key)` - Get flash data

### Middleware

Class-based middleware with decorators:

```typescript
import { Middleware, Context, Next } from '@lockness/core'

@Middleware()
export class AuthMiddleware {
    async handle(c: Context, next: Next) {
        const token = c.req.header('Authorization')
        
        if (!token) {
            return c.json({ error: 'Unauthorized' }, 401)
        }
        
        // Verify token...
        await next()
    }
}

// Use on controller
import { UseMiddleware } from '@lockness/core'

@Controller('/api/admin')
@UseMiddleware(AuthMiddleware) // Apply to all routes
export class AdminController {
    @Get('/users')
    @UseMiddleware(LogMiddleware) // Apply to specific route
    async users(c: Context) {
        return c.json({ users: [] })
    }
}
```

## Common Patterns

### RESTful CRUD

```typescript
@Controller('/api/posts')
export class PostController {
    @Inject(PostService)
    accessor postService!: PostService

    @Get('/', { name: 'posts.index' })
    async index(c: Context) {
        const posts = await this.postService.findAll()
        return c.json({ posts })
    }

    @Get('/:id', { name: 'posts.show' })
    async show(c: Context) {
        const id = Number(c.req.param('id'))
        const post = await this.postService.findById(id)
        return post ? c.json(post) : c.json({ error: 'Not found' }, 404)
    }

    @Post('/', { name: 'posts.store' })
    @Validate('json', insertPostSchema)
    async store(c: Context) {
        const data = c.req.valid('json')
        const post = await this.postService.create(data)
        return c.json(post, 201)
    }

    @Put('/:id', { name: 'posts.update' })
    @Validate('json', updatePostSchema)
    async update(c: Context) {
        const id = Number(c.req.param('id'))
        const data = c.req.valid('json')
        const post = await this.postService.update(id, data)
        return c.json(post)
    }

    @Delete('/:id', { name: 'posts.destroy' })
    async destroy(c: Context) {
        const id = Number(c.req.param('id'))
        await this.postService.delete(id)
        return c.json({ deleted: true })
    }
}
```

## Error Handling

Lockness provides automatic error handler discovery and clean console output.

### Auto-Discovery

The framework automatically detects custom error handlers at:
`app/view/pages/errors/error_handler.tsx`

No manual registration needed in kernel.tsx - it's convention over configuration.

### Create Custom Error Pages

```bash
deno task cli make:error-pages
```

Creates error handler with 404, 401, 403, 500 pages using inline CSS (framework-agnostic).

### Custom Error Handler Example

```typescript
import { Context, formatErrorForConsole, HTTPException } from '@lockness/core'

export function errorHandler(error: Error, c: Context) {
    const status = error instanceof HTTPException ? error.status : 500
    
    // Clean console output with color-coding
    formatErrorForConsole(error, status, c.req.path, {
        showStackTrace: status >= 500,
    })

    if (error instanceof HTTPException) {
        switch (status) {
            case 404: return c.html(<NotFoundPage />, 404)
            case 401: return c.html(<UnauthorizedPage />, 401)
            case 403: return c.html(<ForbiddenPage />, 403)
        }
    }
    
    return c.html(<ServerErrorPage />, 500)
}
```

### HTTP Exceptions

```typescript
// Throw from anywhere
throw new HTTPException(404, { message: 'User not found' })
throw new HTTPException(401, { message: 'Invalid credentials' })
throw new HTTPException(403, { message: 'Access denied' })
```

### Error Formatting

formatErrorForConsole() provides:
- 404: Minimal logging (⚠️ 404 Not Found: /path)
- 401/403: Simple messages
- 500+: Full stack traces with condensed output

## Deployment

### Option 1: Deno Deploy (Recommended)

```bash
# Entry Point: main.ts
# Build Command: deno task routes:generate && deno task css:build
# Environment Variables: APP_ENV=production, DATABASE_URL=...
```

Zero configuration, automatic HTTPS, native TypeScript execution.

### Option 2: Standalone Binary

```bash
deno task compile
```

Creates self-contained executable (~92MB) in _dist/ folder with:
- Deno runtime
- All dependencies
- Static assets (public/ copied to _dist/public/)

Deploy entire _dist/ folder to server:

```bash
scp -r _dist/ user@server:/opt/myapp/
ssh user@server
cd /opt/myapp/_dist
./lockness
```

### Option 3: Direct Execution

```bash
deno task start
# Or: deno run -A --env-file=.env.production.local main.ts
```

### Production Checklist

Environment Variables:
- APP_ENV=production
- SESSION_SECRET=strong-random-value
- DATABASE_URL=postgresql://...

Assets:
- deno task css:build
- deno task routes:generate

Security:
- Disable devtools in kernel.tsx
- Use HTTPS (automatic with Deno Deploy)
- Run database migrations

### Troubleshooting

Static Files 404 (Binary): Deploy entire _dist/ folder, not just binary. Public folder must be at _dist/public/.

Routes Not Found: Run `deno task routes:generate` before `deno task compile`.

## Best Practices

1. **Use Dependency Injection** - Inject services, don't instantiate
2. **Repository Pattern** - Separate data access from business logic
3. **Named Routes** - Use `route()` helper, avoid hardcoded URLs
4. **Validation** - Always validate input with `@Validate`
5. **Flash Messages** - Use `session().flash()` for user feedback
6. **Environment Variables** - Never commit secrets, use .env
7. **Migrations** - Always use migrations, never modify database manually
8. **Type Safety** - Leverage TypeScript and Drizzle's type inference
9. **Error Handling** - Use HTTPException and formatErrorForConsole()
10. **Framework-Agnostic Error Pages** - Use inline CSS in error templates
