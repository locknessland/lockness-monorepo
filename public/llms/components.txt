# Lockness Components

Reusable JSX components for server-side rendered views.

## @lockness/ui Components

Lockness provides a UI component library via `@lockness/ui` inspired by shadcn/ui. Components can be added via CLI (recommended) or imported as a library.

### Adding Components via CLI

```bash
# List all available components
deno run -A jsr:@lockness/ui list

# Add components to your project
deno run -A jsr:@lockness/ui add button card
```

Components are copied to `app/view/components/ui/` by default. This gives you full ownership and customization capabilities.

### Button Component

```tsx
import { Button } from '@view/components/ui/Button.tsx'
// Or from library: import { Button } from '@lockness/ui/components'

// Variants: primary (default), secondary, outline, ghost, danger
<Button variant="primary" size="md">Submit</Button>
<Button variant="outline" size="sm">Cancel</Button>
<Button variant="danger">Delete</Button>

// With Unpoly navigation
<Button up-target=".main" up-href="/users">Load Users</Button>

// Custom styling
<Button class="w-full" type="submit">Sign In</Button>
```

### Class Name Utility (cn)

```tsx
import { cn } from '@view/lib/utils.ts'
// Or from library: import { cn } from '@lockness/ui'

// Merge classes with conflict resolution
const buttonClass = cn(
    'px-4 py-2',
    'bg-blue-500 hover:bg-blue-600',
    isLarge && 'text-lg',
    className // User-provided classes
)

// In components
<Button class={cn('w-full', props.class)}>Submit</Button>
```

The `cn()` utility uses clsx + tailwind-merge to properly handle Tailwind class conflicts.

### Unpoly Integration

All components support Unpoly directives for SPA-like navigation:

```tsx
// Partial page updates
<a up-target=".main" up-href="/users">Users</a>

// Open in modal
<a up-layer="new modal" up-href="/user/new">New User</a>

// Form submission
<form up-submit up-target=".result">
    <input type="text" name="query" />
    <Button type="submit">Search</Button>
</form>

// Preload on hover
<a up-preload up-href="/dashboard">Dashboard</a>
```

## Conditional Rendering

```tsx
export const Alert = (props: { 
    message?: string
    type?: 'success' | 'error' | 'info'
}) => {
    if (!props.message) return null

    const colors = {
        success: 'bg-green-100 text-green-800 border-green-300',
        error: 'bg-red-100 text-red-800 border-red-300',
        info: 'bg-blue-100 text-blue-800 border-blue-300',
    }

    const colorClass = colors[props.type || 'info']

    return (
        <div class={`border rounded p-4 ${colorClass}`}>
            {props.message}
        </div>
    )
}
```

## List Rendering

## Form Components

```tsx
type InputProps = {
    label: string
    name: string
    type?: string
    value?: string
    error?: string
    required?: boolean
}

export const Input = (props: InputProps) => {
    return (
        <div class="mb-4">
            <label class="block mb-2 font-semibold">
                {props.label}
                {props.required && <span class="text-red-500">*</span>}
            </label>
            <input
                type={props.type || 'text'}
                name={props.name}
                value={props.value || ''}
                class={`w-full px-4 py-2 border rounded ${
                    props.error ? 'border-red-500' : 'border-gray-300'
                }`}
                required={props.required}
            />
            {props.error && (
                <p class="text-red-500 text-sm mt-1">{props.error}</p>
            )}
        </div>
    )
}

export const Form = (props: {
    action: string
    method?: string
    children: any
}) => {
    return (
        <form action={props.action} method={props.method || 'POST'}>
            {props.children}
            <button 
                type="submit"
                class="px-6 py-3 bg-blue-500 text-white rounded hover:bg-blue-600"
            >
                Submit
            </button>
        </form>
    )
}
```

**Usage:**
```tsx
<Form action="/posts" method="POST">
    <Input label="Title" name="title" required />
    <Input label="Content" name="content" type="textarea" required />
</Form>
```

## Dynamic Attributes

```tsx
export const Badge = (props: { 
    text: string
    variant?: 'primary' | 'secondary' | 'danger'
}) => {
    const variants = {
        primary: 'bg-blue-500 text-white',
        secondary: 'bg-gray-500 text-white',
        danger: 'bg-red-500 text-white',
    }

    return (
        <span class={`px-3 py-1 rounded text-sm ${variants[props.variant || 'primary']}`}>
            {props.text}
        </span>
    )
}
```

## Helper Components

### Pagination

```tsx
type PaginationProps = {
    currentPage: number
    totalPages: number
    baseUrl: string
}

export const Pagination = (props: PaginationProps) => {
    const pages = Array.from({ length: props.totalPages }, (_, i) => i + 1)

    return (
        <nav class="flex gap-2">
            {props.currentPage > 1 && (
                <a href={`${props.baseUrl}?page=${props.currentPage - 1}`}>
                    Previous
                </a>
            )}
            
            {pages.map(page => (
                <a 
                    href={`${props.baseUrl}?page=${page}`}
                    class={page === props.currentPage ? 'font-bold' : ''}
                >
                    {page}
                </a>
            ))}
            
            {props.currentPage < props.totalPages && (
                <a href={`${props.baseUrl}?page=${props.currentPage + 1}`}>
                    Next
                </a>
            )}
        </nav>
    )
}
```

### Avatar

```tsx
export const Avatar = (props: { 
    src?: string
    alt: string
    size?: 'sm' | 'md' | 'lg'
}) => {
    const sizes = {
        sm: 'w-8 h-8',
        md: 'w-12 h-12',
        lg: 'w-16 h-16',
    }

    return props.src ? (
        <img 
            src={props.src} 
            alt={props.alt}
            class={`rounded-full ${sizes[props.size || 'md']}`}
        />
    ) : (
        <div class={`rounded-full bg-gray-300 flex items-center justify-center ${sizes[props.size || 'md']}`}>
            <span class="text-gray-600 font-semibold">
                {props.alt.charAt(0).toUpperCase()}
            </span>
        </div>
    )
}
```

## Best Practices

- **Pure components** - No side effects, only render
- **Type props** - Use TypeScript interfaces
- **Default props** - Provide sensible defaults
- **Composable** - Break into smaller components
- **Reusable** - Keep generic, avoid business logic
- **Server-side only** - No client-side JavaScript
- **Use Tailwind** - Utility-first CSS classes
- **Consistent naming** - PascalCase for components

## SSR Considerations

Lockness uses **server-side rendering only**:

- No React hooks (useState, useEffect)
- No client-side state management
- No event handlers (onClick, onChange) - use forms
- Pure HTML output
- Excellent SEO
- Fast initial load
- Progressive enhancement

For interactivity:
- Use forms with server-side processing
- Use HTML attributes (autofocus, required)
- Use CSS for animations/transitions
- Add client-side JS separately if needed
