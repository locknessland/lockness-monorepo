# Section

Documentation for the Section component.

## Installation

```bash
deno run -A jsr:@lockness/ui add section
```

## Usage

```tsx
import { Section, SectionHeader, SectionTitle } from '@lockness/ui/components'

<Section id="features" variant="muted" size="lg">
  <SectionHeader>
    <SectionTitle>Features</SectionTitle>
  </SectionHeader>
</Section>
```
