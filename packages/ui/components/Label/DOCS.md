# Label

Documentation for the Label component.

## Installation

```bash
deno run -A jsr:@lockness/ui add label
```

## Usage

```tsx
import { Label } from '@lockness/ui/components'

<Label for="email">Email Address</Label>
<input type="email" id="email" />
```
