# Link

Documentation for the Link component.

## Installation

```bash
deno run -A jsr:@lockness/ui add link
```

## Usage

```tsx
import { Link } from '@lockness/ui/components'

<Link href="/dashboard">Go to Dashboard</Link>
<Link href="/settings" variant="primary">Settings</Link>
```
