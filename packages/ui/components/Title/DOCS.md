# Title

Documentation for the Title component.

## Installation

```bash
deno run -A jsr:@lockness/ui add title
```

## Usage

```tsx
import { Title } from '@lockness/ui/components'

<Title level={1}>Page Title</Title>
<Title level={2}>Section Title</Title>
<Title level={1} size="hero">Hero Title</Title>
```
