# ChartExtras

Documentation for the ChartExtras component.

## Installation

```bash
deno run -A jsr:@lockness/ui add chartextras
```

## Usage

```tsx
import { PieChart } from '@lockness/ui/components'

<PieChart
    chartId='revenue-chart'
    data={[
        { label: 'Income', value: 50, color: 'rgb(59, 130, 246)' },
        { label: 'Outcome', value: 30, color: 'rgb(6, 182, 212)' },
        { label: 'Others', value: 20, color: 'rgb(209, 213, 219)' },
    ]}
    doughnut
/>
```
