# FeatureCard

Documentation for the FeatureCard component.

## Installation

```bash
deno run -A jsr:@lockness/ui add featurecard
```

## Usage

```tsx
import { FeatureCard } from '@lockness/ui/components'

<FeatureCard
    icon={<ZapIcon />}
    title='Blazing Fast'
    description='Sub-millisecond response times'
/>
```
