# Lockness Controllers & Routing

Class-based controllers with decorators for routing and automatic route discovery.

## How Route Discovery Works

Lockness uses **automatic controller discovery** through `@lockness/core`:

**Development Mode (Runtime Discovery):**
- The `App.discoverControllers()` method scans `app/controller/` directory
- Dynamically imports all `.ts`, `.tsx`, `.js` files
- Detects classes decorated with `@Controller()` via `_basePath` metadata
- Instantiates controllers temporarily to initialize TC39 decorator metadata
- Registers routes defined with `@Get()`, `@Post()`, etc. automatically
- Hot-reload with `--watch` picks up changes instantly

**Production Mode (Static Imports):**
- Uses explicit imports from `app/routes.ts` (pre-generated file)
- Enables `deno compile` to bundle controllers into standalone binary
- No runtime scanning needed - all imports are static

**In app/kernel.tsx:**
```typescript
const isDevelopment = Deno.env.get('APP_ENV') === 'development'

if (isDevelopment) {
    await app.init({
        controllersDir: './app/controller', // Auto-discover
    })
} else {
    import { controllers } from './app/routes.ts'
    await app.init({
        controllers, // Explicit imports
    })
}
```

**The app/routes.ts file** is auto-generated when you:
- Run `deno task cli make:controller` (creates controller + updates routes)
- Run `deno task routes:generate` manually
- Use `deno task routes:watch` (optional watcher)

This means: **No manual route registration needed in development!** Just create a controller with decorators and it's automatically discovered.

## Basic Controller

```typescript
import { Controller, Get, Post, Context } from '@lockness/core'

@Controller('/api/users')
export class UserController {
    @Get('/', { name: 'users.index' })
    async index(c: Context) {
        return c.json({ users: [] })
    }

    @Get('/:id', { name: 'users.show' })
    async show(c: Context) {
        const id = c.req.param('id')
        return c.json({ id })
    }

    @Post('/')
    async store(c: Context) {
        const body = await c.req.json()
        return c.json(body, 201)
    }
}
```

## HTTP Method Decorators

- @Get, @Post, @Put, @Delete, @Patch, @Options, @Head

## Named Routes

```typescript
@Controller('/users')
export class UserController {
    @Get('/:id', { name: 'users.show' })
    async show(c: Context) { ... }
}

// Generate URLs
import { route } from '@lockness/core'
const url = route('users.show', { id: 123 }) // "/users/123"
return c.redirect(route('auth.login'))
```

## CLI Commands

```bash
# Create controller
deno task cli make:controller User                 # JSON API
deno task cli make:controller User --view          # With JSX view

# Add action to existing controller
deno task cli make:action User show                # GET method
deno task cli make:action User store --method=post # POST method
deno task cli make:action User create --view       # With view
```

## RESTful Conventions

| Action  | Method | Path      | Route Name     |
|---------|--------|-----------|----------------|
| index   | GET    | /         | resource.index |
| show    | GET    | /:id      | resource.show  |
| create  | GET    | /create   | resource.create|
| store   | POST   | /         | resource.store |
| edit    | GET    | /:id/edit | resource.edit  |
| update  | PUT    | /:id      | resource.update|
| destroy | DELETE | /:id      | resource.destroy|
