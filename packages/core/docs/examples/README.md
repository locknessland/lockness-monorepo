# @lockness/core Documentation Examples

This directory contains example code demonstrating various features of the
Lockness framework.

## Available Examples

### `on_boot_example.tsx`

Demonstrates how to use the `@OnBoot` decorator for organizing application
initialization logic with priority-based execution.

**Topics covered:**

- Basic `@OnBoot` usage
- Priority-based execution order
- Modular boot tasks
- Migration from traditional bootstrap pattern

See `../kernel.md` for complete documentation on the boot lifecycle system.
