### 🔒 TypeScript Type Safety Standards

> Maximize type safety to catch errors at compile time.

**Required Practices:**

- ❌ **Avoid `any`** - Use proper types or `unknown` with type guards
- ✅ **Explicit return types** - All public functions must declare return types
- ✅ **`readonly`** - Use for immutable properties and arrays
- ✅ **Generics** - Use for reusable, type-safe code
- ✅ **Discriminated unions** - Use for state management
- ✅ **Type guards** - Use for runtime type validation

**When `any` is Required:**

```typescript

```

**Type Guard Example:**

```typescript
function isUser(value: unknown): value is User {
    return (
        typeof value === 'object' &&
        value !== null &&
        'id' in value &&
        'email' in value
    )
}
```

## 📦 Creating a New Package

When creating a new package in `/packages/`, follow this structure:

### Required Package Structure

```
packages/[package-name]/
├── .github/                    # GitHub-specific files (optional)
├── deno.json                   # Package manifest (required)
├── mod.ts                      # Main entry point (required)
├── types.ts                    # Type definitions (if needed)
├── README.md                   # Package documentation (required)
├── docs/
│   └── DOCS.md                 # User-facing documentation
└── tests/
    └── [feature].test.ts       # Unit tests
```

### Package deno.json Template

```json
{
    "name": "@lockness/[package-name]",
    "description": "Brief description of the package",
    "version": "0.1.0",
    "license": "MIT",
    "exports": "./mod.ts",
    "tasks": {
        "test": "deno test -A tests/",
        "test:watch": "deno test -A --watch tests/"
    },
    "publish": {
        "include": [
            "mod.ts",
            "types.ts",
            "deno.json",
            "README.md"
        ],
        "exclude": [
            "tests/"
        ]
    },
    "imports": {
        "@std/assert": "jsr:@std/assert@1"
    }
}
```

### Package mod.ts Template

````typescript
/**
 * @fileoverview Brief description of the package.
 *
 * Detailed explanation of what this package provides.
 *
 * @module @lockness/[package-name]
 *
 * @example
 * ```typescript
 * import { Feature } from '@lockness/[package-name]'
 *
 * const feature = new Feature()
 * ```
 */

export { Feature } from './feature.ts'
export type { FeatureOptions } from './types.ts'
````

## 🎨 Creating a New UI Component

When creating a new UI component in `/packages/ui/components/`, follow this
structure:

### Required Component Structure

```
packages/ui/components/[ComponentName]/
├── mod.tsx          # Main component (required)
├── examples.tsx     # Usage examples (required)
└── DOCS.md          # Component documentation (required)
```

### Component mod.tsx Template

````tsx
/**
 * @fileoverview ComponentName component description.
 *
 * Detailed explanation of what this component provides.
 *
 * @module @lockness/ui/components/[component-name]
 */

import type { FC, PropsWithChildren } from '@lockness/core'
import { cn } from '../../lib/utils.ts'

/**
 * ComponentName props
 */
export interface ComponentNameProps extends PropsWithChildren {
    /** Description of prop */
    propName?: string
    /** Additional CSS classes */
    class?: string
}

/**
 * ComponentName component description.
 *
 * @example
 * ```tsx
 * <ComponentName propName="value">Content</ComponentName>
 * ```
 */
export const ComponentName: FC<ComponentNameProps> = ({
    propName,
    class: className,
    children,
}) => {
    return (
        <div class={cn('base-classes', className)}>
            {children}
        </div>
    )
}
````

### Component examples.tsx Template

```tsx
/**
 * @fileoverview ComponentName examples for documentation.
 *
 * @module @lockness/ui/components/[component-name]/examples
 */

import { ComponentName } from './mod.tsx'

/**
 * Basic usage example
 */
export const BasicExample = () => (
    <ComponentName>Basic content</ComponentName>
)

/**
 * With custom props
 */
export const CustomExample = () => (
    <ComponentName propName='custom'>Custom content</ComponentName>
)
```

### Component DOCS.md Template

```markdown
# ComponentName

Brief description of the component.

## Import

\`\`\`tsx import { ComponentName } from '@lockness/ui/components' \`\`\`

## Usage

\`\`\`tsx
<ComponentName propName="value">Content</ComponentName> \`\`\`

## Props

| Prop     | Type    | Default | Description         |
| -------- | ------- | ------- | ------------------- |
| propName | string  | -       | Description of prop |
| class    | string  | -       | Additional CSS      |
| children | unknown | -       | Component content   |

## Examples

### Basic

\`\`\`tsx
<ComponentName>Basic content</ComponentName> \`\`\`

### With Props

\`\`\`tsx
<ComponentName propName="value">Content</ComponentName> \`\`\`
```

### Exporting the Component

Add to `/packages/ui/components.ts`:

```typescript
// [Category] Components
export { ComponentName } from './components/ComponentName/mod.tsx'
export type { ComponentNameProps } from './components/ComponentName/mod.tsx'
```
