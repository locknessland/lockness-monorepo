# Internationalization (i18n)

`@lockness/i18n` adds message catalogs, `t()` with ICU interpolation and
pluralization (on Deno's built-in `Intl` — **zero dependencies**), and a
per-request locale resolver that bridges the existing locale routing.

## Configure

```ts
// kernel.tsx
import en from './resources/lang/en-us.ts'
import fr from './resources/lang/fr-fr.ts'

@Kernel({
    i18n: {
        catalogs: { 'en-us': en, 'fr-fr': fr },
        defaultLocale: 'en-us', // should equal config/i18n.ts's defaultLocale
    },
})
class AppKernel {}
```

`@lockness/core` soft-loads `@lockness/i18n` at boot and calls `configureI18n`.
Catalogs are TS modules (statically importable — SSG expands locales at build
time), keyed by locale, supporting nested or dot-keyed messages:

```ts
// resources/lang/en-us.ts
export default {
    greet: 'Hi {name}',
    cart: { items: '{count, plural, one {# item} other {# items}}' },
    role: '{r, select, admin {Administrator} other {Member}}',
}
```

## Translate

```ts
import { getTranslator } from '@lockness/i18n'

class HomeController {
    index(c: Context) {
        const t = getTranslator(c) // lazy, resolved from the request
        return c.text(t.t('cart.items', { count: 3 })) // '3 items'
    }
}
```

`t()`/`trans()` return a **plain string** — the view layer escapes (Hono JSX
auto-escapes). A missing key returns the key itself; nothing throws. Keys
cascade per-key through the language chain: `en-us` → `en` → fallback → default.

The ICU subset: `{name}` interpolation, cardinal `{n, plural, …}` (with `=N`
exact cases, `#`, and `offset:`), and `{v, select, …}`. Ordinal plurals, nested
submessages, and number/date skeletons are a scoped follow-up.

## Per-request locale

Resolution is **lazy** — `getLocale(c)` / `getTranslator(c)` resolve on first
call (after the mount middleware set the route locale) from **route → cookie →
header → default** (order configurable). The resolved locale is always in the
configured set: a raw `Accept-Language` / cookie value is validated (and
bounded) before any lookup, and an unknown value falls back to the default.

### Ambient `t()` in views

To use `t()` deep in JSX without prop-drilling, install the eager middleware
(runs the request in an `AsyncLocalStorage` scope) and import the ambient `t`:

```ts
import { localeMiddleware, t } from '@lockness/i18n'

app.useMiddleware(localeMiddleware()) // inner of the locale mount
 // in any component rendered during the request:
<h1>{t('greet', { name: user.name })}</h1>
```

## Tooling

```bash
deno task cli make:lang fr-fr    # scaffold resources/lang/fr_fr.ts
deno task cli i18n:extract ./app # report t('…') keys used in source
```

`make:lang` validates the locale (a BCP-47-like shape) and refuses to write
outside `resources/lang/`. `i18n:extract` reports string-literal keys and flags
dynamic keys as un-extractable (never guessed).
